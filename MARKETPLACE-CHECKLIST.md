# Marketplace release checklist

- [ ] Change the demo values in `src/brand.ts`.
- [ ] Replace all demo images and video clips with redistributable assets.
- [ ] Update the browser title and meta description in `index.html`.
- [ ] Review the homepage, contact page, and footer for client-specific copy or links.
- [ ] Test the site on mobile and desktop.
- [ ] Test navigation, reduced-motion behaviour, and video loading.
- [ ] Confirm forms show a helpful fallback without environment variables.
- [ ] Add your own Formspree IDs only in `.env` or host settings; never include them in the download.
- [ ] Run `npm run lint` and `npm run build` from a clean install.
- [ ] Add preview screenshots, a live demo URL, feature list, requirements, and support policy to the marketplace listing.
- [ ] Remove unnecessary source media and system files before packaging.
